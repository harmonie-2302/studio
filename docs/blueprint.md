# **App Name**: Harmy's Atelier

## Core Features:

- Homepage: Home page displaying a welcome message and a brief introduction to Harmy'sewing atelier.
- Service Showcase: A 'Services' page showcasing the atelier's services with photos of already made models.
- Contact Form: Contact form for customers to fill in their name, address, and phone number.
- AI Model Suggestion: Gemini AI integration to suggest clothing models and designs based on user preferences. Gemini acts as a tool, creatively proposing fashion ideas tailored to each client's needs.

## Style Guidelines:

- Primary color: Dusty rose (#C8A2C8) to evoke sophistication and craftsmanship.
- Background color: Very light gray (#F0F0F0) for a clean, neutral backdrop that puts focus on the clothing designs.
- Accent color: Lavender (#E6E6FA) to add a touch of elegance and highlight key interactive elements.
- Headline font: 'Belleza', a humanist sans-serif for a personality and fashion-forward look. Body font: 'Alegreya', a humanist serif, which will add an elegant and intellectual touch. 
- Use elegant, custom-designed icons related to sewing, fashion, and design services.
- Clean and modern layout with a focus on visual presentation of clothing models. Grid layout for service showcase.
- Subtle transitions and animations for a smooth and engaging user experience. Animated loading states while Gemini generates design suggestions.
